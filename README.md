# אתר הוצאת סול

דף נחיתה מלא בעברית להוצאת סול, כולל קטלוג, חיפוש, סינון והשוואת מחירים לפי מודפס, דיגיטלי וקולי. המחיר הנמוך בכל פורמט מסומן אוטומטית.

## עדכון אוטומטי

הקובץ `scripts/update-from-evrit.mjs` מרענן את קטלוג סול ומשווה מחירים מעברית, ביבוקס, סטימצקי, צומת ספרים ואינדיבוק:

- ספרים חדשים שהתווספו לקטלוג
- מחירים ומחירי מבצע
- פורמטים דיגיטלי, מודפס וקולי
- עטיפות
- דירוגים ומספר ביקורות
- הופעה ברשימות רבי־המכר השבועיות של עברית, ביבוקס ואינדיבוק

הפעולה ב־GitHub Actions רצה אחת ל־6 שעות, ולאחר העדכון מפרסמת את האתר מחדש ב־GitHub Pages. אפשר גם להפעיל אותה ידנית מתוך לשונית Actions.

## פרסום

1. מעלים את תוכן התיקייה למאגר GitHub חדש.
2. ב־Settings → Pages בוחרים Source: GitHub Actions.
3. מפעילים את הפעולה `Update Sol catalog and deploy` או דוחפים שינוי לענף `main`.

המחיר הקובע תמיד הוא המחיר שמוצג באתר החנות בזמן הרכישה.
